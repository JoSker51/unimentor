# UniMentor

Prototipo web de una plataforma universitaria de mentorías entre estudiantes
(estilo Uber matching + chat académico). Hecho en un solo archivo `index.html`
con React + Tailwind vía CDN — **no requiere instalar nada**.

## Cómo correrlo (para alguien que no sabe nada del tema)

No se necesita Node, Python ni programas. Solo un navegador (Chrome / Edge /
Firefox) e internet.

### Opción A — Descargar y abrir (la más fácil)

1. Abre `index.html` en este repositorio.
2. Haz clic en **"Download raw file"** (ícono ⬇️ arriba a la derecha del código).
3. Ve a tu carpeta de **Descargas** y haz **doble clic** en `index.html`.
4. Se abre solo en el navegador. ¡Listo!

### Opción B — Descargar todo el proyecto

1. Botón verde **"Code"** → **"Download ZIP"**.
2. Clic derecho al ZIP → **"Extraer todo"**.
3. Doble clic en `index.html`.

## Cómo usar la app

1. En el login, elige un rol: **"Busco ayuda"** o **"Quiero ser mentor"**.
2. Clic en **"Iniciar sesión"** (los campos ya vienen con datos de ejemplo).
3. Navega con el menú de la izquierda.
4. Flujo recomendado (estudiante): **Solicitar ayuda** → enviar →
   esperar el matching → **Aceptar mentor** → se abre el **chat**.

## Si no se ve bien

- Necesita internet la primera vez (carga estilos desde la web).
- Si sale en blanco: espera unos segundos y refresca con **F5**.
- Mejor en Chrome o Edge, en pantalla de computador o tablet.
